# AHP Pertamina Pertagas Niaga — Localhost

## 1. Install Python
Pastikan Python 3.10+ sudah terinstall.

## 2. Buka terminal di folder project
Contoh:
cd AHP-Pertamina-Localhost

## 3. Install library
pip install -r requirements.txt

## 4. Jalankan aplikasi
streamlit run app.py

## 5. Buka browser
Biasanya:
http://localhost:8501

## Catatan
Aplikasi menggunakan data perbandingan AHP yang dimasukkan melalui browser.
Nilai contoh bukan data resmi PT Pertamina Pertagas Niaga. Untuk penelitian, masukkan hasil kuesioner/data primer atau data matriks yang tervalidasi.
